# 連絡板（業務アプリ全体の連絡網）

業務アプリ全体をまたぐ連絡・周知を、ポータルの1か所に集めて掲示し、
選んだ宛先へ **LINE WORKS で一斉通知**する仕組みです。現場への展開の入口として使います。

```
ポータルの連絡板（投稿）
   ├─▶ ポータルに掲示（誰でも後から読み返せる・返信できる）
   └─▶ LINE WORKS へ一斉通知（工場長など、LINE WORKS ID が登録されている人）
```

- 実装: `api/notices.js`（API） / `index.html` の「連絡板」
- 各アプリの画面に散らさず、**ポータルに1つだけ**置く方針です
  （見る場所が一意に決まり、見逃しが起きにくいため）

## 使い方

ポータルにログインすると、**「アプリ一覧」「連絡板」の2つのタブ**が出ます。
未読があると連絡板タブに件数バッジが付くので、アプリ一覧を見ている人も気付けます。

### 連絡を投稿する（管理者）

「連絡板」タブの **「連絡を投稿」** から、次を入力します。

| 項目 | 内容 |
| --- | --- |
| 対象アプリ | どのアプリの話か。通知の見出しに出る（「ポータル全体・その他」も可） |
| 宛先 | **全員**、または特定の**部署・工場**。ここで選んだ人にだけ通知が飛ぶ |
| 件名 | 100文字以内 |
| 本文 | 2000文字以内 |

投稿できるのは**管理者（役割 admin）またはポータル管理権限を持つ人**です。
周知の手段なので一般ユーザーには開放していません（**返信は誰でもできます**）。

投稿すると「LINE WORKS へ ○名に通知しました」と件数が出ます。0名のときは
通知先が1人も登録されていないので、管理画面でユーザーの LINE WORKS ID を確認してください。

### 届くメッセージ

```
【生産計画】生産計画アプリ 入力手順の変更

来週より入力画面が変わります。
詳細はポータルをご確認ください。

— 工場長 一郎

▼ポータルで確認・返信
https://portal.paloma-pf.com
```

### 読む・返信する

連絡板には**自分に宛てられた連絡だけ**が並びます（全員宛て＋自分の所属部署宛て）。
未読には赤い「新着」が付き、タブに未読件数が出ます。「内容を見る」で開くと既読になります。

各連絡の**対象アプリのタグはそのままリンク**になっていて、押すとそのアプリが開きます
（ポータル経由の自動ログインつき）。連絡を読んでから現物を確認するまでが1クリックで済みます。
ただし、そのアプリを使えない人にはリンクを出しません（押しても起動できないため）。
具体的には、所属部署に割り当てられていないアプリと、一般ユーザーから見た管理者専用アプリ
（人事管理・進捗管理）はタグのままです。

返信するとその連絡の**投稿者と、すでに返信した人**へ LINE WORKS で通知が届きます
（宛先全員に返信を流すと通知が多くなりすぎるため、やり取りしている人だけに送ります）。

## 通知先の決まり方

宛先に選んだ範囲の中で、**LINE WORKS ID（未登録ならメールアドレス）が入っている人**へ送ります。
どちらも未登録の人は、ポータルの連絡板でのみ確認できます（通知は飛びません）。

LINE WORKS ID の登録は「管理画面 → ユーザー設定 → ユーザーの編集」から行います。
詳細は `docs/lineworks.md` を参照してください。

## 制限・仕様

| 項目 | 値 |
| --- | --- |
| 件名 | 100文字 |
| 本文・返信 | 2000文字 |
| 一覧の表示件数 | 直近100件 |
| 1投稿あたりの通知上限 | 300名（超過分は送らず、件数を画面とログに出します） |

- 連絡の削除は**投稿者本人またはポータル管理権限者**のみ。返信も一緒に削除されます
- 本文・返信中の `http(s)://` で始まるURLは自動でリンクになります。それ以外はすべて
  エスケープして表示するため、HTMLやスクリプトが実行されることはありません
- LINE WORKS が未設定でも連絡板は動作します（掲示のみ行い、通知はスキップ）
- 通知の送信に失敗しても、投稿・返信は保存されます

## API（参考）

すべて利用者セッション（ポータルのログイン）が必要です。

| メソッド | 内容 |
| --- | --- |
| `GET /api/notices` | 自分宛ての一覧（返信・既読状態・投稿権限・宛先候補を含む） |
| `GET /api/notices?unread=1` | 未読件数のみ |
| `POST /api/notices` `{action:"post", ...}` | 投稿（管理者のみ）→ 宛先へ一斉通知 |
| `POST /api/notices` `{action:"reply", id, body}` | 返信 → 投稿者・既返信者へ通知 |
| `POST /api/notices` `{action:"read", id}` | 既読にする |
| `DELETE /api/notices` `{id}` | 削除（投稿者本人・ポータル管理権限者） |
